# Jogo: Jornada dos Deuses do Egito

Um jogo web simples e visualmente bonito sobre mitologia egípcia.

## Como abrir

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Ou use um servidor simples, como:

```bash
python -m http.server 8000
```

Depois acesse:

`http://localhost:8000`

## Estrutura do projeto

- `index.html` — página principal
- `styles.css` — layout e visual
- `script.js` — lógica do jogo

## Descrição

O jogo apresenta uma sequência de perguntas sobre deuses egípcios, com imagens temáticas e pontuação final.

## GitHub Pages

Se você habilitar o GitHub Pages no repositório, a URL ficará no formato:

`https://SEU_USUARIO.github.io/jogo-deuses-egito/`

Substitua `SEU_USUARIO` pelo seu nome de usuário do GitHub.
